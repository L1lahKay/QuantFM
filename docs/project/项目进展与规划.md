## 0. 目前进展

A 股全市场 Level-2 订单流基础模型（QuantFM）的 V1 数据链路与训练系统已跑通；**22 日全市场（302M）预训练已完成（40000 个当时代码语义下的 micro-steps，best val_loss 5.3288）**。由于 `grad_accum=2` 时旧 `state.step` 在每个 micro-batch 增加，这不能对外表述为 40000 次 optimizer updates。

当前分支新增的是**底层 V2 与严格 OOS 研究基础设施**，而不是新的实盘业绩结论：

- 订单簿撤单/FIFO 一致性修复，并增加因果 `BookState`、`cn_l2_v2`和紧凑盘口特征。
- Tokenizer V2 固化 `FieldSpec`，分离 `PAD/UNK/NA/...` ID，使用确定性分层 reservoir，同时输出 token 和连续 scalar。
- 模型增加 scaled/gated/concat 字段融合、field dropout、entropy-normalized CE、ordinal 辅助损失与 applicability mask，并保留 V1 `legacy_sum` 兼容。
- embedding 修复跨 chunk `last/last-k` 语义，增加多尺度聚合；5 分钟时钟、PIT 行业 join、leave-one-out/O(N) 股票间上下文作为独立研究模块落地。
- 下游增加 ReturnSpec、execution panel、缓冲 Top-K/成本模型、风险归因与独立 score 评估；生产交付契约仍是 `date, symbol, score`。

截至本快照，全量测试为 `243 passed, 2 skipped, 1 xfailed`。这些测试证明接口、因果性和兼容契约，**不证明 V2 已提升 RankIC 或收益**；25M/100M 多 seed 消融和新的 untouched OOS 仍待执行。

**数据修订（回测有效性）**：早期下游 panel 用 22 个**不连续**交易日，`fwd_ret` 跨多日、不具「次日」意义，回测年化不可解释。已建设连续 60 日研究链，并进一步用显式 `ReturnSpec` 区分 `close_t_close_t1` 与可交易的 T+1 入场口径。既有 2026 连续 60 日 score 已参与本轮方案形成，只能作为 architecture validation，不再是 untouched OOS。历史 `cont60` 运行记录（`quant_fm/runs/cont60`，2025-01-02 ~ 2025-04-07）为：
- 连续 panel 已建成（`panel/daily_panel_cont60.parquet`，31.2 万行，交易日间隔校验全部 = 1）；
- `attach_fwd_ret` 改为**全局交易日历下一交易日**对齐，`fwd_ret = close(T+1)/close(T)-1`；
- 连续 60 日全市场 tokens 正在后台生产（复用预训练冻结 vocab，`run_medium --reuse-vocab`，过夜级）；
- `run_cont60_downstream.sh` 已挂起等待，manifest 就绪后自动抽 embedding + 跑 judge，届时年化指标首次达 `min_days=60` 可信门槛。

## 2. 已完成（Done）

### 2.1 数据 Infra 与订单簿引擎

- **pylob 沪深订单簿重建引擎**：集合竞价 + 连续竞价 + 上交所/深交所规则差异；撤单同步从价格档 deque 与 `orders` 索引删除，中间撤单不破坏 FIFO，空价格档及时清理。
- **MinIO 读写分离**：`:9000` 读原始行情（`zeus-cn-quote`）/ `:9100` 写训练产物（`model-cache/fm-pretrain`）；含上传、下载、断点恢复脚本。
- **全链路数据管道**：`clean → events → tokens → manifest`，支持按日增量、`.done` 标记续跑、`--drop-clean/--drop-events` 控制磁盘峰值、`--fit-sample-days` 分箱采样、`--max-symbols-per-market` 规模试跑。
- **V2 因果状态基础**：`BookStateTransition(pre, post)`、`cn_l2_v2` 与 MinIO/Pilot/Medium 一键编排已接通；V2 规范化强制读取回放捕获的真实盘口列，缺失时 fail closed。



### 2.2 Tokenizer 与防泄漏

- V1 9 字段 token 化：6 个类别字段 + 3 个连续字段（`price_rel` / `log_volume` / `log_delta_t`）。
- 连续字段 32 桶分位数分箱，**仅用训练日期拟合**并缩尾，写入 `vocab.json` 冻结。
- `assert_no_leakage()` 强校验验证/测试日期未参与分箱拟合（medium_300m 日志实测通过）。
- V2 增加 `FieldSpec`、独立 `NA`、确定性分层 reservoir、占用率/熵诊断与 token+scalar 输出；V1/V2 artifact 严格分目录保存。



### 2.3 预训练系统

- **模型**：OrderFlowFM，Decoder-only + RMSNorm + SwiGLU + RoPE。V1 保留各字段 embedding 直接求和与 6 个 next-event 头；V2 可配置 scaled/gated/concat 融合与 scalar projection。
- **训练循环**：FSDP + bf16 + 梯度累积 + warmup 余弦 LR；完整 checkpoint（model/optimizer/scaler/step）+ `--resume auto`；TensorBoard 记录 train/val loss 与 per-field CE。
- **V2 loss / 评估**：显式 TargetSpec、有效目标 mask、训练集熵归一化、ordinal 辅助损失、固定分层验证窗口和 per-field CE/accuracy/NLL/gradient norm 已实现。
- **多档配置就绪**：V1 pilot（~6M）、medium_try（~80M）、302M等；V2 新增约 25M/100M 消融配置，但尚未完成正式多 seed 训练。

## 附：链路总览

```text
MinIO :9000 / zeus-cn-quote（原始 L2）
  → pylob 订单簿重建 → clean/
  → cn_l2_v1 规范事件 → events/
  → 训练日 fit_bins → vocab.json（冻结）
  → tokenize → tokens/
  → build_manifest → manifest.json（按交易日切分 + 防泄漏）
  → FSDP 预训练（OrderFlowFM）→ best.pt
  → 股日 embedding
  → ranker → RankIC / CPCV / DSR / 带成本 Top-K 回测
MinIO :9100 / model-cache ← 备份 tokens / vocab / manifest / checkpoint
```

V2 研究链不覆盖上述产物：

```text
exchange-order replay
  → causal pre/post BookState → cn_l2_v2
  → frozen FieldSpec + vocab_v2 → token + scalar shards
  → field fusion + entropy-normalized/ordinal next-event loss
  → fixed validation plan → V2 checkpoint
  → cross-chunk multi-scale pooling → optional intraday aggregator
  → optional 5m PIT cross-asset context
  → frozen ranker → date, symbol, score
  → independent execution panel / strict OOS research evaluation
```
