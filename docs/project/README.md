## 文件归档约定

- 新的定期汇报使用 `近期工作汇报-YYYY-MM-DD.md`，并更新本页“当前入口”。
- 一次性执行计划使用可识别任务名；任务结束后保留日期和实际结果，不覆盖为新计划。
- 稳定的架构设计放入 [`../architecture/`](../architecture/)，运行手册放入
  [`../operations/`](../operations/)，数据流程放入 [`../data/`](../data/)。
- 实验原始证据放入 [`../assets/`](../assets/) 的对应主题目录，正文只保留结论和相对链接。
- 本地运行产物、凭据、个人材料与大文件不迁入本目录，也不纳入版本控制。
