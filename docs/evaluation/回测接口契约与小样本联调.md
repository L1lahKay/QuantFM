# QuantFM 回测接口契约与小样本联调

> 契约版本：`1.0`  
> 样本性质：纯合成、仅供接口联调，不是 Dense230M 信号。

## 1. 一键生成隔离样本

```bash
uv run python -m quant_fm.scripts.build_backtest_contract_fixture \
  --out-root quant_fm/runs/backtest_contract_fixture_v1
```

`--out-root` 必须是不存在的新目录，生成器不会覆盖已有文件，也不会读取或修改
`quant_fm/runs/oos2026_dense230/delivery_oos`。输出为：

```text
backtest_contract_fixture_v1/
├── README.md
├── SAMPLE_ONLY.md
├── source_signal/
│   ├── scores.parquet
│   └── signal_manifest.json
├── backtest_delivery/
│   ├── README.md
│   ├── scores.parquet
│   ├── signal_manifest.json
│   ├── delivery_manifest.json
│   └── reports/SAMPLE_ONLY.md
└── backtest_delivery.tar.gz
```

回测端使用 `backtest_delivery/` 或压缩包联调。`source_signal/` 用于证明冻结打包前后
主数据和生产生成器的两文件输出完全一致。

## 2. 稳定主数据契约

`scores.parquet` 只有以下三列，名称、顺序与物理类型都必须严格一致：

| 顺序 | 列 | Parquet/Polars 类型 | 约束 |
|---:|---|---|---|
| 1 | `date` | string / `String` | 有效 `YYYY-MM-DD` |
| 2 | `symbol` | string / `String` | 六位数字、左补零、不带交易所后缀 |
| 3 | `score` | float64 / `Float64` | 非 null、NaN、Inf |

- 主键为 `(date, symbol)`，不得重复；
- 表不得为空；缺失股票表示当日无信号，不得补零；
- `score` 越大越看多，但只保证同一交易日截面可比；
- `score(T)` 使用 T 日信息，在 T 日收盘后可用，最早 T+1 执行；
- 不得加入 `label`、`fwd_ret`、价格、可成交性、持仓或收益列。

## 3. Manifest 必需字段

`signal_manifest.json` 的稳定部分为：

```json
{
  "format_version": "1.0",
  "score_semantics": {
    "direction": "higher_is_more_bullish",
    "availability": "available_after_signal_date_close",
    "comparability": "cross_sectional_within_date"
  },
  "data": {
    "file": "scores.parquet",
    "schema": {"date": "string", "symbol": "string", "score": "float64"},
    "primary_key": ["date", "symbol"],
    "rows": 8,
    "dates": 2,
    "date_min": "2026-01-05",
    "date_max": "2026-01-06"
  }
}
```

真实生产包可额外带 artifact 哈希、Ranker 配置和说明；接收端应允许未知扩展字段，但
必须严格校验上述字段和 `scores.parquet` 一致。联调样本额外包含
`fixture.synthetic=true`，用于防止被误认为真实信号。

冻结包的 `delivery_manifest.json` 记录包内每个交付文件的字节数和完整 SHA-256；读取
主数据前应先验证它。该清单本身不属于模型输出的两文件接口。

## 4. 接收端最小验收

若接收环境安装了 QuantFM：

```python
from pathlib import Path

from quant_fm.scripts.package_signal_delivery import validate_signal_directory

scores, manifest = validate_signal_directory(
    Path("backtest_contract_fixture_v1/backtest_delivery")
)
print(scores.shape, manifest["score_semantics"])
```

若只安装 Polars，最低检查如下：

```python
import math

import polars as pl

s = pl.read_parquet("backtest_contract_fixture_v1/backtest_delivery/scores.parquet")
assert s.columns == ["date", "symbol", "score"]
assert s.schema == {"date": pl.String, "symbol": pl.String, "score": pl.Float64}
assert s.height > 0
assert not s.select(["date", "symbol"]).is_duplicated().any()
assert s["date"].str.contains(r"^\d{4}-\d{2}-\d{2}$").all()
assert s["symbol"].str.contains(r"^\d{6}$").all()
assert all(math.isfinite(value) for value in s["score"])
```

## 5. 联调通过标准与真实包切换

回测端应在样本上确认：

1. 保留 `symbol` 的字符串类型和前导零；
2. 以 `(date, symbol)` 对齐 PIT 股票池，不做行号对齐；
3. 每个日期单独排序/标准化，不跨日期比较 score 绝对值；
4. 将 `date` 当作信号日，最早映射到下一个交易日执行；
5. 缺失股票保持无信号，过滤和成交失败时不使用未来信息补选；
6. 包内文件哈希、行数、日期范围和 schema 全部校验通过。

真实 Dense230M 包就绪后，只替换交付目录或压缩包路径，解析逻辑与验收规则不得改变。
联调样本不得进入收益评估、模型比较或交易流程。
